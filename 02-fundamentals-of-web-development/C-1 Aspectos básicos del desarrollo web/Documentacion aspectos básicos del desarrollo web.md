# Documentación del Curso "Fundamentos del Desarrollo Web" - Módulo 1: Aspectos Básicos del Desarrollo Web

En el primer módulo del curso "Fundamentos del Desarrollo Web", se cubren conceptos fundamentales sobre las funciones de una computadora y los aspectos clave del desarrollo web.

## Funciones de una Computadora

Todos los ordenadores tienen cuatro funciones esenciales:

1. **Entrada**: Recibe información a través de dispositivos como teclados y ratones.
2. **Procesamiento**: Transforma los datos a través de operaciones lógicas.
3. **Salida**: Muestra los resultados en pantallas, altavoces, etc.
4. **Almacenamiento**: Guarda los datos temporal o permanentemente (ej. RAM o disco duro).

## Componentes de la Computadora

Una computadora necesita tanto:

- **Hardware**: Componentes físicos como la CPU, la RAM y los dispositivos de entrada/salida.
- **Software**: El sistema operativo (ej. Windows, Linux) y las aplicaciones (ej. navegadores web, editores de texto).

## Lenguajes de Programación

Los lenguajes de programación se dividen en:

- **Lenguaje Binario (Máquina)**: El único lenguaje que la computadora entiende directamente.
- **Lenguajes Compilados (C, Java)**: Se traducen completamente a código máquina antes de ejecutarse, son rápidos pero necesitan recompilación.
- **Lenguajes Interpretados (Python, JavaScript)**: Se ejecutan línea por línea y son más flexibles y fáciles de modificar.

## Desarrollo Web vs. Diseño Web

- **Desarrollo Web**: Se enfoca en la funcionalidad del sitio (código, bases de datos, servidores). Utiliza lenguajes como HTML, CSS, JavaScript, Python.
- **Diseño Web**: Se enfoca en la experiencia visual del usuario. Utiliza herramientas como Figma, Adobe XD.

## Componentes de un Sitio Web

Un sitio web consta de:

- **Nombre de dominio y URL**: La dirección única del sitio (ej. www.ejemplo.com).
- **Navegador**: El software que interpreta y muestra el sitio (ej. Chrome, Firefox).
- **Servidor**: Computadora que aloja los archivos del sitio y los entrega a los usuarios.

## Proceso de Desarrollo Web

Los pasos para crear un sitio web son:

1. **Planificación y Diseño**: Definir los requisitos y crear wireframes.
2. **Codificación**: Escribir el código en HTML, CSS y JavaScript.
3. **Pruebas**: Verificar que todo funcione correctamente (enlaces, formularios, accesibilidad).
4. **Publicación**: Subir el sitio a un servidor para hacerlo accesible en Internet.
5. **Mantenimiento**: Actualizar contenido, corregir errores y mejorar funcionalidades.

## Front-End vs. Back-End

- **Front-End (Cliente)**: Lo que el usuario ve y usa. Usa HTML, CSS, JavaScript.
- **Back-End (Servidor)**: Lo que pasa detrás de escena, gestionando bases de datos, autenticación y lógica del servidor. Usa lenguajes como Python, Java, PHP.

## Internet vs. World Wide Web

- **Internet**: Red global de computadoras interconectadas que funciona con protocolos como TCP/IP.
- **World Wide Web (WWW)**: Es la colección de sitios web accesibles a través de Internet.

## La Nube y el Desarrollo Web

La computación en la nube ofrece ventajas como:

- **Alojamiento escalable**: Servidores flexibles según la demanda.
- **Distribución de cargas**: Mejor rendimiento para sitios con alto tráfico.
- **Almacenamiento seguro**: Bases de datos y archivos accesibles desde cualquier lugar.
