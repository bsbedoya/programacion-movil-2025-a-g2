# Documentación del Curso: Fundamentos del Desarrollo Web

En el segundo módulo del curso "Fundamentos del Desarrollo Web", exploré los fundamentos esenciales del desarrollo web. Este módulo se centró en entender cómo se crean los sitios web y los lenguajes clave utilizados por los desarrolladores.

## Los Navegadores: Los Obreros del Desarrollo Web

Los navegadores web, como **Chrome**, **Firefox** y otros, actúan como los "obreros" que leen los "planos" (código HTML) para mostrar las páginas web. El marcado (como HTML) resuelve varios problemas clave en el desarrollo web:

- **Evita archivos pesados.**
- **Mejora la compatibilidad entre diferentes dispositivos y navegadores.**
- **Hace que la web sea accesible para todos.**

## HTML: La Estructura de la Web

HTML es el esqueleto de la web. Utilizando etiquetas como `<header>` o `<article>`, HTML5 organiza el contenido de una forma lógica y accesible. Las características clave de HTML incluyen:

- **Estructura y organización del contenido.**
- **Despedida de Flash**: ahora podemos usar videos y animaciones nativas en lugar de Flash.

## CSS: El Diseño de la Web

CSS (Cascading Style Sheets) es el lenguaje utilizado para definir el estilo y la apariencia de una página web. Algunas características importantes de CSS son:

- **Los estilos se heredan**: los elementos hijo heredan el estilo de los elementos padre, lo que facilita la gestión del diseño.
- **Reutilización de código**: los desarrolladores pueden usar clases para aplicar el mismo estilo a varios elementos.
- **Control de apariencia**: CSS define colores, fuentes, márgenes y otros aspectos visuales.

## JavaScript: La Interactividad de la Web

JavaScript es el lenguaje que hace que los sitios web sean interactivos. Permite realizar tareas como:

- **Activar botones**.
- **Gestionar formularios**.
- **Actualizar la página sin necesidad de recargar**.

JavaScript nació en los años 90 con Netscape y hoy sigue siendo el lenguaje más utilizado en la web para interactividad.

## Metodologías Ágiles: Más Flexibilidad

En el desarrollo de software, los enfoques tradicionales como el **método en cascada** eran lentos y rígidos. Hoy en día, las metodologías ágiles, como **Scrum**, se han convertido en la norma. Las características clave de este enfoque incluyen:

- **Trabajo en sprints cortos**.
- **Feedback constante**.
- **Más flexibilidad y menos sorpresas** durante el ciclo de desarrollo.

## Lecciones Aprendidas del Curso

1. **Importancia de los estándares web**: como HTML5 y CSS3, para garantizar la compatibilidad y la accesibilidad de las páginas web.
2. **Colaboración entre HTML, CSS y JavaScript**:
   - HTML estructura el contenido.
   - CSS lo diseña.
   - JavaScript lo hace interactivo.
3. **Metodologías ágiles**: el uso de metodologías como ágil y Scrum es esencial para gestionar proyectos web de manera eficiente.
4. **Habilidades prácticas**: como identificar etiquetas semánticas y aplicar estilos con CSS, que son fundamentales para crear sitios web modernos y efectivos.

## Conclusión

Este módulo ha proporcionado una base sólida para comprender los elementos fundamentales del desarrollo web moderno. HTML, CSS y JavaScript son tecnologías esenciales que trabajan juntas para construir sitios web funcionales y atractivos. Además, las metodologías ágiles proporcionan un enfoque eficiente y flexible para gestionar proyectos de desarrollo web.
