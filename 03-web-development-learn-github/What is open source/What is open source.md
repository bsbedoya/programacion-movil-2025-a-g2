# ¿Qué significa "open source"?

El término **open source** (código abierto) se refiere a algo que las personas pueden modificar y compartir porque su diseño es públicamente accesible.

Originalmente, el término surgió en el contexto del desarrollo de software, pero hoy en día representa un conjunto más amplio de valores, conocido como **"the open source way"**.

Los proyectos, productos o iniciativas open source adoptan y celebran principios como:

- Intercambio abierto
- Participación colaborativa
- Prototipado rápido
- Transparencia
- Meritocracia
- Desarrollo orientado a la comunidad

---

## ¿Qué es el software de código abierto?

El **software de código abierto** es aquel cuyo código fuente puede ser inspeccionado, modificado y mejorado por cualquier persona.

> **Código fuente**: es la parte del software que los programadores pueden modificar para cambiar el funcionamiento de un programa o aplicación.

---

## Diferencias entre software open source y software propietario

| Característica          | Open Source                       | Propietario                          |
| ----------------------- | --------------------------------- | ------------------------------------ |
| Acceso al código fuente | Abierto a todos                   | Solo disponible para el creador      |
| Modificación            | Permitida por la licencia         | Prohibida o restringida              |
| Ejemplos                | LibreOffice, GIMP                 | Microsoft Office, Adobe Photoshop    |
| Licencias               | Fomentan uso libre y colaboración | Restringen uso, modificación y copia |

---

## Licencias de software open source

- Permiten el uso, estudio, modificación y distribución del software.
- Algunas licencias **copyleft** requieren que cualquier versión modificada también publique su código fuente.
- No permiten cobrar licencias por compartir el software, aunque sí por servicios adicionales.

---

## ¿Es solo para programadores?

No. Tanto la **tecnología open source** como el **pensamiento open source** benefician a programadores y no programadores:

- Internet se construyó con tecnologías open source como **Linux** y **Apache**.
- Muchas funciones diarias como navegar, enviar correos o jugar online dependen del open source.

---

## ¿Qué es la computación en la nube?

Cuando se usan aplicaciones a través del navegador o apps móviles que están en servidores remotos, hablamos de **computación remota** o **computación en la nube**.

Ejemplos:

- **Propietarios**: Google Apps
- **Open source**: ownCloud, Nextcloud

> Plataformas como **OpenStack** permiten crear infraestructura cloud open source.

---

## ¿Por qué la gente prefiere software open source?

### 1. Control

Permite revisar y cambiar lo que hace el software.

### 2. Aprendizaje

Ideal para estudiantes y desarrolladores que quieren aprender leyendo y modificando código.

### 3. Seguridad

Cualquier persona puede detectar y corregir errores. Esto lleva a software más estable y seguro.

### 4. Estabilidad

No depende de una sola empresa. Es ideal para proyectos a largo plazo.

### 5. Comunidad

Se forman comunidades activas de usuarios y desarrolladores que contribuyen y mejoran el software.

---

## ¿"Open source" significa gratis?

No necesariamente.

- Los desarrolladores pueden **cobrar** por su software open source.
- También pueden ganar dinero ofreciendo **servicios y soporte técnico**.
- Las habilidades en software open source son altamente valoradas por empleadores.

---

## ¿Qué es el open source más allá del software?

El **pensamiento open source** también se aplica a otras áreas:

- Ciencia
- Educación
- Gobierno
- Manufactura
- Salud
- Derecho
- Dinámicas organizacionales

### Principios del open source way:

- Disposición a compartir
- Colaboración abierta
- Transparencia
- Aprendizaje a partir de los errores
- Mejora continua accesible para todos

> El mundo está lleno de “códigos fuente”: recetas, reglas, planos… y deberían ser abiertos para que todos puedan mejorarlos.
