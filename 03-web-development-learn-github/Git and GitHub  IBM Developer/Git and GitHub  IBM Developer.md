# Acerca de esta Actividad Formativa

¿Quieres convertirte en un experto en GitHub? Esta sesión está diseñada para llevarte desde lo básico hasta la práctica efectiva de flujos de trabajo profesionales con Git y GitHub.

---

## Objetivo de Aprendizaje

Al finalizar esta actividad, serás capaz de:

- Comprender los fundamentos de **git** y su estructura.
- Utilizar **GitHub** para alojar, colaborar y gestionar proyectos de software.
- Aplicar buenas prácticas en la creación de ramas y manejo de *pull requests*.
- Configurar correctamente el entorno de trabajo local (CLI) para trabajar con repositorios remotos.

---

## Contenidos Principales

### 1. Fundamentos de Git

- ¿Qué es Git y por qué es importante en el desarrollo moderno?
- Estados de un archivo: *untracked*, *staged*, *committed*.
- Comandos esenciales (`git init`, `git add`, `git commit`, `git status`, `git log`).

### 2. Introducción a GitHub

- ¿Qué es GitHub y cómo complementa a Git?
- Crear una cuenta en GitHub.
- Repositorios públicos vs privados.
- Licencias, README, y archivos `.gitignore`.

### 3. Configuración del Entorno

- Instalación de Git en tu sistema operativo.
- Configuración del usuario (`git config`).
- Generación de llaves SSH y conexión con GitHub.
- Configuración del editor por defecto.

### 4. Flujo de Trabajo con Pull Requests (PR)

- ¿Qué es una *pull request* y por qué es importante?
- Crear y gestionar ramas.
- Clonar un repositorio y trabajar en una nueva funcionalidad.
- Subir cambios y abrir una PR.
- Revisión, comentarios y *merge* de PRs.

### 5. Buenas Prácticas

- Escribir mensajes de *commit* claros y descriptivos.
- Nombrar ramas de forma coherente (`feature/`, `bugfix/`, `hotfix/`).
- Uso de issues y proyectos en GitHub.
- Automatización con GitHub Actions (mención introductoria).
